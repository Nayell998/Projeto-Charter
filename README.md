Biblioteca Solidaria Sistema simples
Título do projeto
 Biblioteca Solidaria
 Desenvolver um Sistema simples que registre empréstimos e devoluções de Livros
Problema
Falta de controle de empréstimo de livros, causando perdas e confusão, sem saber 
quem está com o livro, é impossível prever quando ele estará disponível novamente. 
registro adequado, livros podem desaparecer sem que se saiba quem os levou ou 
quando.
Público-alvo
Estudantes e moradores locais 
Profissionais que precisão registar os livros 
Métricas de sucesso
-Código funcionar sem erros
-Sistema fácil de usar
